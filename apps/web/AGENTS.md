# Web scope

- Use strict TypeScript, server components by default, and small accessible client
  components only where interaction requires them.
- Reuse components and design tokens. Pages must remain responsive, keyboard
  operable, and intelligible without color alone.
- Never treat hidden controls as authorization. The API is the policy boundary.
- Clearly label user-provided, computed, inferred, and validated scientific data.
- Biological diagrams must use real mapping data and expose ambiguity/provenance.
- Run lint, type checking, component tests, and a production build after changes.
