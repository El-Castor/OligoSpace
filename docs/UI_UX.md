# UI and interaction direction

The product uses a calm, light scientific workspace: warm white surfaces, ink text,
teal primary actions, blue biological accents, and amber only for warnings. Dense
tables retain generous row rhythm and visible filters. Monospace sequence text is
selectable and wraps by bases, never truncated without an expansion affordance.

Desktop navigation follows Overview; Research (Oligos, Targets, Assays,
Experiments); Lab (Inventory, Orders, Validation); Workspace (Projects, Team); and
System (Admin). Global search is persistent. Mobile navigation prioritizes search,
stock scanning, tube moves, and low/depleted actions.

Status is conveyed by label, icon/shape, and color. Focus is visible. Dialogs trap
focus and restore it. Tables expose accessible names and keyboard navigation.
GeneOligoViewer will render real coordinates in SVG, explicit strand arrows, assay
toggles, transcript selection, ambiguity banners, tooltips, and a textual fallback.
